Web Tools

Skillflo 업무를 도와주는 내부 도구 모음입니다.

📚
강의 정보 정리
강의명을 입력하면 AI가 정보를 요약해 엑셀로 다운로드할 수 있습니다.
💡
강의 추천
조건을 입력하면 적합한 강의를 추천받을 수 있습니다.
📂
과정 리스트
전체 과정 목록을 검색하고 필터링합니다.
🏷️
카테고리 자동 분류
강의명을 붙여넣으면 AI가 카테고리를 자동으로 분류합니다.
🧾
결과 보고서
Skillflo raw data 3종을 업로드하면 수강 강의 현황부터 접속 유저수까지 자동으로 계산합니다.
📖
수강 리포트
기업별 월간 수강 이력을 업로드하면 AI가 학습 현황을 분석해 서술형 코멘트가 담긴 리포트를 생성합니다.
✉️
수강안내메일 에디터
수강 시작 안내 메일 템플릿을 편집하고 HTML로 복사합니다.
📣
독려메일 에디터
일반/수료기준/필수강의 독려 메일 템플릿을 편집하고 HTML로 복사합니다.
🧩
패키지강의 생성 가이드
패키지 구독 강의 생성 과정을 스크린샷 핫스팟으로 따라 해보는 인터랙티브 가이드입니다.
📘
가이드센터
Skillflo 사용자용 도움말 센터입니다. 카테고리·검색·HOT 아티클을 확인할 수 있습니다.
🛠️
가이드센터 관리자
가이드센터의 카테고리·아티클을 리치텍스트로 작성·편집하고 HOT 픽을 관리합니다.
💰
콘텐츠 정산 시스템
CP사·계약·상품·매출을 관리하고 월별 콘텐츠 정산을 계산·확정합니다. (일부 정산 공식은 추정 구현 — 계약 관리 화면 참고)
👥
구성원 다운로드
Skillflo 파트너 포털에서 기업별 구성원 명단을 자동으로 내려받습니다.
🏢
기업 리스트
기업(멤버그룹)별 CSM/AE, 플랜, 운영 일정, 담당자 정보를 관리합니다.
📈
기업 현황 대시보드
CSM 담당자별 ongoing/closed 기업 수 현황을 한눈에 확인합니다.
